# server-outwittrader

Server-side project for **OutwitTrader** built with **Node.js + TypeScript**.  
Provides REST APIs with database integration, middleware, and Docker setup for easy development and deployment.

---

## 🔧 Tech Stack
- **Runtime:** Node.js (TypeScript)
- **Framework:** Express
- **ORM/DB:** TypeORM (configured in `AppDataSource.ts`)
- **Containerization:** Docker & docker-compose
